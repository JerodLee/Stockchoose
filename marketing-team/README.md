# 마케팅팀 (AI Marketing Team) — 범용 시스템

AI 직원(스킬)들이 협업해 마케팅 업무를 수행하는 **상품 무관 범용 시스템**입니다.
GUI에서 모든 작업을 관리·실행하고, 실제 AI 생성만 클로드코드가 담당합니다.

## 두 개의 화면
| 파일 | 용도 |
|---|---|
| **workbench.html** | 🛠️ **워크벤치** — GUI에서 캠페인 생성·상품 입력·작업 요청·결과 관리까지 모두 실행 (인터랙티브) |
| **dashboard.html** | 📊 **관제 대시보드** — 팀 상태·파이프라인·산출물 모니터링 (읽기 전용, data/team.json 기반) |

## 워크벤치 — GUI에서 모든 작업 진행
- **범용:** 어떤 상품/캠페인이든 재사용. 캠페인을 만들고 상품·브리핑만 입력하면 됨.
- **직원 관리:** 기본 9직원 + `＋직원 추가`로 무한 확장(스킬 코드는 `skills/` 폴더명과 매칭).
- **작업 보드:** 요청됨(큐) → 진행중 → 완료. 직원 카드의 `＋작업 요청`으로 큐에 추가.
- **저장:** 브라우저 localStorage(새로고침 유지). `⋯`에서 JSON 백업/이전.

## 클로드코드 경계 (실제 AI가 하는 부분)
GUI는 작업을 **큐에 넣고**, 실제 생성은 클로드코드가 합니다 (반자동):
1. 큐 작업의 `🤖 클로드코드로` 클릭 → **완성된 프롬프트**가 나옴 → 복사해서 클로드코드에 붙여넣기
2. 클로드코드가 카피/이미지/리서치 등 생성
3. 결과를 워크벤치에 `📥 결과 입력` → 저장하면 **완료** 처리
> API 키·백엔드 없이 동작. 완전 자동화(버튼→Agent SDK 자동 호출)는 백엔드 연동 시 확장 가능.

## 구성
```
marketing-team/
├── workbench.html          🛠️ GUI 워크벤치 (모든 작업 실행)
├── dashboard.html          📊 관제 대시보드 (모니터링)
├── data/team.json          대시보드용 상태 원본
├── bin/log-work.mjs        직원 작업 기록 CLI
├── bin/build.mjs           대시보드 스냅샷 빌드
├── skills/*/SKILL.md       직원 업무 매뉴얼 (product-discovery, product-selection,
│                            review-management, customer-support …)
└── outputs/                산출물 문서
```

> ⚠️ AI는 모르면 지어냅니다 — 스펙·수치는 실제 상품 데이터로 검증/교체(허위광고 리스크).
> 오픈마켓 자동 발굴은 쿠팡/네이버 공식 API 또는 헤드리스 브라우저 필요.
