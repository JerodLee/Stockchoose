# 마케팅팀 (AI Marketing Team)

AI 직원(스킬)들이 협업해 마케팅 업무를 수행하는 작업 공간입니다. "무선 미니선풍기" 캠페인 데모로 구성돼 있습니다.

## 구성
```
marketing-team/
  skills/
    product-selection/SKILL.md   # 🏆 우수상품 선정관 (신규 직원)
  outputs/
    우수상품-선정-리포트.md          # 선정관이 만든 리포트
  dashboard.html                  # 📊 팀 관제 대시보드 (직원 상태·산출물 한눈에)
```

## 직원(스킬) 목록
| 직원 | 스킬 | 하는 일 |
|---|---|---|
| 📋 전략기획관 | product-marketing | 제품·타깃 포지셔닝 문서 |
| 🏆 우수상품 선정관 | product-selection | 후보 상품 평가 → 우수상품 선정 + 선정사유 |
| ✍️ 카피라이터 | copywriting | 상세페이지 판매 문구 |
| 📣 광고기획관 | ad-creative | 광고 크리에이티브 |
| 🎨 이미지 디자이너 | image | 비주얼·웹툰 |
| 🎥 영상 제작자 | video | 릴스·쇼츠 영상 |

## 대시보드 보기
`dashboard.html`을 브라우저로 열면 각 직원의 상태·산출물, 오늘의 작업 흐름, 우수상품 선정 결과를 한 화면에서 볼 수 있습니다.

> ⚠️ 우수상품 점수는 실측이 아닌 카테고리 통념 기반 가정치입니다. 실제 판매 전 데이터 검증 필요.
