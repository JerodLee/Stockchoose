## 1. 요약 (Summary)

### 확인된 핵심 (A)
- **전략 성격**: 화려한 스캘핑이 아니라 "지루할 정도로" 단순·반복적인 **추세선 매매**. 인내심과 규칙 준수가 핵심이라는 메시지.
- **트랙레코드 주장**: 약 **11년** 동안 이 방식을 유지, 누적 **$526,454** 수익.
- **톤**: "boring = 좋은 것" — 매매 횟수를 줄이고 확실한 셋업만 기다리는 저빈도(low‑frequency) 접근.

### 전략의 표준 구성 (B, 일반 규칙 기준)
1. **추세 정의**: 상승추세는 고점이 높아지는 저점(higher lows)을 이어 추세선을 긋고, 하락추세는 낮아지는 고점(lower highs)을 잇는다.
2. **진입(Entry)**: 가격이 추세선 / 주요 이동평균(20·50 EMA) / 피보나치 되돌림(50% 부근)으로 **되돌림(pullback)** 한 뒤, 반전 캔들·지지 확인이 나올 때 추세 방향으로 진입.
3. **손절(Stop)**: 상승추세면 직전 스윙 저점 바로 아래, 하락추세면 직전 스윙 고점 바로 위.
4. **목표(Target) / 리스크관리**: 통상 **손익비 1:2 이상(R‑multiple)**, 이전 고점·저항/지지 부근에서 익절.
5. **필터**: 확실치 않은 구간은 건너뛰고(=지루함), 큰 추세와 같은 방향의 셋업만 취한다.

## 2. 가능성 체크 (Feasibility Check)

### 2‑1. 전략 논리 자체 — **타당함 (일반적으로 검증된 계열)**
추세선 풀백 매매는 널리 문서화된 정통 기법입니다. "추세 방향 + 되돌림 진입 + 스윙 기준 손절 + 1:2 손익비"는 구조적으로 건전합니다. 즉 **방법론 자체는 현실적이고 재현 가능**합니다.

### 2‑2. 수익 금액 주장($526,454) — **가능하지만 맥락 없이는 검증 불가**
| 항목 | 평가 |
|---|---|
| 11년 누적 $526,454 | 연 환산 약 **$47,800/년**. 전업이 아니라면 충분히 나올 수 있는 규모이며, "월 수만 달러"류 과장 영상보다 오히려 **현실적인 편**. |
| 검증 한계 | 초기 자본금·평균 계좌 크기·레버리지·최대낙폭(MDD)·승률이 **공개되지 않으면 수익률(%)로 환산 불가**. 절대 금액만으로는 리스크 대비 성과를 알 수 없음. |
| 생존편향 | "성공한 11년"만 보여주는 영상 특성상 실패 사례·중도 청산 위험은 축소되기 쉬움. |

### 2‑3. 현실적 리스크 (반드시 감안)
- **후행성**: 추세선은 그리는 사람마다 달라지는 주관적 도구. 백테스트 재현성이 낮을 수 있음.
- **횡보장 취약**: 추세가 없는 구간에서는 잦은 손절(whipsaw) 발생.
- **심리**: "지루함을 견디는 것"이 실제로는 가장 어려운 부분 — 규칙 이탈이 성과를 무너뜨림.
- **거래비용/세금**: 국내 적용 시 수수료·거래세·양도세가 손익비 가정을 잠식.

### 2‑4. 결론 (한 줄)
> **전략 = 현실적이고 건전한 정통 기법. 수익 금액 = 과장은 아니나, 자본·리스크 지표 없이는 "복제 가능성"을 단정할 수 없음.** 검증하려면 명확한 규칙으로 코드화해 **백테스트(승률·평균 R·MDD)** 를 돌려보는 것이 정답.

## 3. 이 프로젝트(Stockchoose)와의 연결 — 실행 가능성

이 저장소는 트레이딩 대시보드(Next.js)입니다. 위 전략을 **실제로 코드화해 검증하는 백테스트 모듈을 추가**했습니다.

- [x] 규칙을 파라미터로 명세화 → `app/lib/backtest.ts` (`BacktestParams`: EMA 기간 / 되돌림 기준 / 손익비 R / 손절 오프셋 / 최대 보유)
- [x] 백테스트 엔진 → **승률·평균 R·Profit Factor·MDD·기대값** 산출 (영상의 절대금액 대신 %·R로 판정)
- [x] 결과 패널 → `app/components/BacktestPanel.tsx` (대시보드 하단 "BORING MODE"), Equity 곡선 + $ 환산(계좌 1% 리스크)
- [x] 손익비(1:1.5 / 1:2 / 1:3) 토글 · "새 데이터로 재검증" 버튼으로 시드별 강건성 확인

### 백테스트가 말해주는 것 (합성 데이터 기준)
- 손익비 1:2에서 **승률이 40%대여도 기대값이 양(+)** 으로 나온다 → 영상의 "지루하지만 통한다"는 주장의 **구조적 근거**를 재현.
- 단, 여기 데이터는 **결정적(seed) 합성 OHLC**이며 모멘텀이 이어지는 성질이 있어 승률이 다소 높게 잡힘. **실거래 검증에는 실제 과거 데이터 연결이 필요**하다.
- 즉 "방법론은 양의 기대값을 가질 수 있다"까지는 재현되나, **영상의 $526,454 절대금액은 자본·기간·리스크 설정에 전적으로 의존**한다는 §2 결론은 그대로 유지된다.

### 실행 방법
```bash
npm install
npm run dev   # http://localhost:3000 → 하단 우측 "TRENDLINE PULLBACK · BACKTEST" 패널
```
